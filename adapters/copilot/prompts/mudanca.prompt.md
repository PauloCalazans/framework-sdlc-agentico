description: Mudança pequena de comportamento pela trilha enxuta (um documento → Gate 1 → RED → GREEN → revisão → PR).

Siga `.claude/commands/mudanca.md` como orquestrador. Nele, `$ARGUMENTS` é o texto que o humano escreveu junto com este comando, e despachar um papel é invocar o agente personalizado de mesmo nome (`.github/agents/<papel>.agent.md`).
